Лабораторная работа №1
Представление чисел в памяти компьютера
Вариант b: BCD-2421

Как открыть в Visual Studio:
1. Откройте файл Lab1VariantB.sln.
2. Убедитесь, что установлен Python workload для Visual Studio.
3. Запустите main.py.

Как запустить программу из консоли:
python main.py

В меню программы есть пункт:
8. Запустить Unit-тесты и показать покрытие кода

Как запустить тесты отдельно:
run_tests.bat

Что проверяется:
- перевод целых чисел в прямой, обратный и дополнительный коды;
- сложение в дополнительном коде;
- вычитание через отрицание вычитаемого и сложение;
- умножение в прямом коде;
- деление в прямом коде с точностью 5 знаков;
- операции IEEE-754 binary32;
- сложение чисел в BCD-2421;
- проверка ошибок ввода;
- запуск меню;
- покрытие кода.

Результат проверки текущей версии:
19 тестов пройдено.
Общее покрытие: 95%.

В основной логике не используются eval, bin(), format() и обычный float для решения операций IEEE-754.
