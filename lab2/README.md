# Лабораторная работа №2

**Тема:** построение СКНФ и СДНФ на основании таблиц истинности.

Проект реализован на Python без `eval()` и без сторонних библиотек, решающих основную задачу лабораторной работы.
Для тестирования используется стандартный модуль `unittest`. Для отчёта покрытия используется инструмент `coverage`.

## Возможности программы

1. Ввод булевой функции в свободном формате.
2. Поддержка операций: `!`, `¬`, `&`, `∧`, `|`, `∨`, `->`, `→`, `~`.
3. Поддержка переменных `a`, `b`, `c`, `d`, `e`.
4. Построение таблицы истинности.
5. Построение СДНФ и СКНФ.
6. Вывод числовых форм СДНФ и СКНФ.
7. Вывод индексной формы функции.
8. Проверка принадлежности к классам Поста: T0, T1, S, M, L.
9. Построение полинома Жегалкина.
10. Поиск фиктивных переменных.
11. Булева частная и смешанная дифференциация.
12. Минимизация ДНФ расчётным и расчётно-табличным методом.
13. Минимизация КНФ расчётным и расчётно-табличным методом.
14. Минимизация ДНФ и КНФ методом карт Карно с выводом таблицы.

## Запуск программы

```bash
python run.py
```

На Windows можно запустить:

```bash
run_project.bat
```

## Запуск тестов

```bash
python -m unittest discover -p "test_*.py"
```

## Запуск покрытия

```bash
python run_coverage.py
```

или вручную:

```bash
python -m coverage run -m unittest discover -p "test_*.py"
python -m coverage report -m
```

## Структура проекта

- `run.py` — точка входа;
- `main.py` — русскоязычное меню;
- `bool_parser.py` — собственный парсер булевых выражений;
- `truth_table.py` — таблица истинности;
- `normal_forms.py` — СДНФ, СКНФ, числовые формы, индексная форма;
- `post_classes.py` — классы Поста;
- `zhegalkin.py` — полином Жегалкина;
- `differentiation.py` — булева дифференциация;
- `minimization_dnf.py` — минимизация ДНФ;
- `minimization_cnf.py` — минимизация КНФ;
- `karnaugh.py` — карты Карно;
- `test_*.py` — unit-тесты.
